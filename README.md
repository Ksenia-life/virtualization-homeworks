# Основы виртуализации и контейнеризации

Учебные проекты по работе с виртуальными машинами, Docker и развёртыванием приложений.

В ходе курса я работала с Ubuntu, VirtualBox, Vagrant, Docker, Docker Compose, Nginx и PostgreSQL.

## Выполненные работы

### 1. Виртуальная машина с Ubuntu и Nginx

- Развернула виртуальную машину Ubuntu 22.04 с помощью Vagrant и VirtualBox
- Написала Bash-скрипт provision.sh, который автоматически устанавливает и настраивает Nginx
- Настроила запуск веб-сервера и подготовила тестовую HTML-страницу
- Проверила работу сервера через браузер и HTTP-запросы

**Технологии:** Linux, Ubuntu, Vagrant, VirtualBox, Bash, Nginx.

Файлы проекта лежат в корне репозитория, результаты проверок — в папке evidence/.

### 2. Контейнеризация фронтенд-приложения

- Настроила сборку и запуск небольшого веб-приложения в Docker
- Написала Dockerfile с многоэтапной сборкой (multi-stage build)
- Для сборки использовала Node.js и Vite
- Подключила Nginx для раздачи готовых файлов приложения
- Убедилась, что контейнер запускается и приложение доступно.

**Технологии:** Docker, Dockerfile, Node.js, Vite, Nginx.

[Исходный код и инструкция по запуску](homework-2-containerization/README.md)

### 3. Виртуальная инфраструктура с Docker Compose

Итоговое домашнее задание - запуск нескольких сервисов в виртуальной машине Ubuntu.

- Создала виртуальную машину через Vagrant и VirtualBox
- Написала Bash-скрипт для установки Docker, Docker Compose и настройки UFW
- Запустила три контейнера: Nginx, тестовое приложение и PostgreSQL
- Настроила сеть контейнеров, а данные PostgreSQL сохранила в Docker volume
- Убедилась, что приложение доступно, контейнеры работают, а данные не пропадают после перезапуска

**Технологии:** Linux, Vagrant, VirtualBox, Bash, Docker, Docker Compose, Nginx, PostgreSQL, SSH, UFW.

[Исходный код и инструкция по запуску](final-assignment/README.md)
