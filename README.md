# Домашнее задание 1: Основы виртуализации

Проект поднимает Linux VM через Vagrant и VirtualBox
На виртуалке стоит Ubuntu 22.04 LTS

При запуске автоматически выполняется скрипт provision.sh:
- устанавливает nginx,
- включает nginx как сервис,
- создаёт тестовую HTML-страницу с ФИО, группой и датой

Команды для работы:
- vagrant up --provider=virtualbox - запустить VM,
- vagrant status — проверить статус VM,
- vagrant ssh - зайти внутрь VM

Зависимости: Vagrant и VirtualBox

Проверить с хоста: открыть http://127.0.0.1:8080

Логи команд находятся в файле - evidence/commands.log

## Домашнее задание 2: Основы контейнеризации

Второе задание находится в папке:

```text
homework-2-containerization/
```

В нём подготовлена контейнеризация фронтенд-приложения:

- `Dockerfile` — сборка образа через multi-stage build;
- `.dockerignore` — исключение лишних файлов из контекста сборки;
- `README.md` — команды сборки, запуска и проверки;
- `evidence/` — файлы с подтверждением результата.

## Итоговое домашнее задание

Итоговое задание находится в папке:

```text
final-assignment/
```

Внутри лежат:

- `Vagrantfile` — конфигурация виртуальной машины;
- `provision.sh` — установка Docker, Docker Compose и настройка firewall;

- `nginx.conf` — конфигурация reverse proxy;
- `.env` — переменные окружения для PostgreSQL;
